# qcc — пульт управления qico

`qcc` — ncurses-клиент к уже запущенному демону qico. Сам почту не принимает и не звонит: подключается к сокету демона и показывает очередь, лог и сессии, а команды отправляет демону. Выход из `qcc` мейлер не останавливает.

Поведение ниже соответствует исходникам в `src/` (`qcc.c`, `daemon.c`, `protfm.c`, `qipc.c`, `qcconst.h`, `queue.c`, `ftn.c`).

## Запуск

```
qcc [-P порт] [-a хост] [-w пароль] [-n] [-h] [-v]
```

| Опция | Значение |
|---|---|
| `-P порт` | порт демона. По умолчанию служба `qicoui` или порт **60178** |
| `-a хост` | хост. По умолчанию `localhost` |
| `-w пароль` | пароль. `-w-` спрашивает пароль в терминале |
| `-n` | тихий режим, без писка |
| `-h` | краткая справка по опциям |
| `-v` | версия |

Если демон требует пароль, а его нет, `qcc` сразу завершается. При успешном входе клиент регистрируется как получатель событий и начинает получать очередь, лог и обновления сессий.

## Экран

Сверху вниз пять полос:

1. **Заголовок** — `[номер/всего]`, имя окна (`master` или линия), заголовок сессии, справа часы.
2. **Верхнее окно** (около 10 строк; на низком терминале сжимается) — очередь, карточка сессии или текст чата.
3. **Нижнее окно** — лог. У `master` лог только дописывается. У линии хранятся последние **256** строк, их можно листать.
4. **Строка статуса** — то, что демон пишет как текущую фазу (`Waiting N…`, этап протокола и тому подобное).
5. **Подсказка клавиш** и версия `qcc-…`. Подсказка меняется в зависимости от окна.

Буквы в нижней подсказке часто нарисованы заглавными. Программа различает регистр. Точный регистр — в таблицах ниже и в справке **F1** (она печатается в лог текущего окна).

Окна — это слоты. **Master** (очередь демона) — отдельное окно. Каждая модемная линия и каждая IP-сессия — своё окно. Чат — ещё одно окно поверх линии: имя линии переписывается в префикс `CHT…` или `IP…`.

## Переключение окон

| Клавиша | Действие |
|---|---|
| `1`…`9` | окно линии с этим номером. В заголовке `[1/…]` соответствует клавише `1` |
| `0` или `` ` `` | вернуться на master |
| **Tab** | следующее окно; с последнего — снова на master |
| **Right** | следующее окно; на последнем останавливается |
| **Left** | предыдущее окно; на master останавливается |
| **F10**, `q` | выйти из qcc |
| **F1** | вписать краткую справку в лог |
| **Ctrl+L** | перерисовать экран |

В строке очереди `>` — курсор, `=` слева — с этим адресом уже есть живая сессия. Жирная строка — узел сейчас дозванивается.

Колонки очереди: адрес, объём нетмейла, объём файлов (включая freq), число попыток, флаги. Пустая очередь показывается как `* Empty queue *`.

## Флаги очереди

Буквы слева направо. Точка на месте буквы значит, что флаг снят.

| Буква | Смысл |
|---|---|
| `N` | normal, обычный poll |
| `H` | hold, звонить не будет |
| `D` | direct |
| `C` | crash |
| `I` | immediate, звонить сразу |
| `R` | есть file request |
| `U` | undialable, узел снят с обзвона |
| `d` | идёт набор |
| `r` | пауза, пока в очереди только freq |
| `x` | пауза, пока в очереди только arcmail |
| `w` | операторская пауза на всё, в том числе hold по таймеру |

`N`, `H`, `D`, `C` и `R` приходят из файлов аутбаунда. С клавиатуры меняются `I`, `U` и `w`.

## Master: очередь

| Клавиша | Что делает |
|---|---|
| **Up / Down** | курсор по очереди |
| **PgUp / PgDn** | на страницу |
| **Home / End** | в начало / в конец |
| `r` | пересканировать аутбаунд |
| `R` | перечитать конфиг. Открытые сессии при этом продолжаются |
| **Space** | сбросить паузу между дозвонами: демон сразу ищет, кому звонить |
| `p` | poll. Спросит адрес |
| `f` / `F` | информация из нодлиста. `F` — узел под курсором, `f` — спросить адрес |
| `e` / `E` | file request. `E` — текущий узел, `e` — спросить адрес |
| `s` / `S` | прицепить файл к аутбаунду. `S` — текущий узел, flavor normal |
| `k` / `K` | удалить аутбаунд узла так, будто он уже отправлен |
| `I` / `i` | поставить / снять immediate |
| `U` / `u` | поставить undialable / снять его и обнулить счётчик попыток |
| `W` / `w` | поставить паузу на всё / снять все паузы (`w`, `r` и `x`) |
| `h` | hold на N минут (спросит число). Снимается клавишей `w` |

В нижней подсказке hold выглядит как `H`, poll как `P`. Работают строчные `h` и `p`.

### Адрес в строке ввода

Адрес дополняется основным AKA, который демон присылает при подключении. При AKA `2:203/910`:

| Ввод | Результат |
|---|---|
| `.99` | `2:203/910.99` |
| `.1` | `2:203/910.1` |
| `910.3` | `2:203/910.3` |
| `201/127` | `2:201/127` |
| `2:5030/1374` | `2:5030/1374` |

Поле, записанное нулём, остаётся таким, как в AKA. При AKA `2:203/910` и `0`, и `2:203/0` превращаются в `2:203/910`. Аплинк `2:203/0` этой строкой ввода не набирается.

Допустимы цифры, `:`, `/`, `.`, пробел, `@` и буквы flavor `i`, `c`, `d`, `h`, `n`, `y`. Число больше 32767 не принимается. Пустой **Enter** отменяет команду.

### Poll (`p`)

В адресе можно указать flavor:

| Буква | Flavor |
|---|---|
| `n` | normal. Подставляется, если буквы нет |
| `c` | crash |
| `d` | direct |
| `h` | hold |
| `i` | immediate |

Пример: `i201/127` при AKA `2:203/910` — immediate-poll узла `2:201/127`. `d5030/1374` — direct-poll узла `2:5030/1374`.

### File request (`e` / `E`)

После адреса задаётся вопрос `File(s) for request:`. Несколько имён разделяются пробелом. Имя с пробелом берётся в кавычки. Для `e` буква flavor должна остаться `n`: введите адрес без `c`, `d`, `h`, `i`. Иная буква отменяет команду.

### Send (`s` / `S`)

Спрашивается полный путь к файлу. Файл должен быть читаем на машине, где работает демон. Если файл недоступен, в лог пишется предупреждение, и команда всё равно уходит. Пробелы в имени заменяются на `?`. У `s` flavor берётся из буквы в адресе (`n`, `c`, `d`, `h`, `i`). У `S` flavor всегда normal, адрес — узел под курсором.

### Kill (`k` / `K`)

Подтверждение — буква `y` в той же строке.

- `K` — вопрос про узел под курсором, ответ `y`.
- `k` — адрес вместе с `y`, например `y.99` для `2:203/910.99` или `y201/127` для `2:201/127`.

Демон проходит исходящие файлы так же, как после успешной передачи: удаление, обработка `^`-файлов и остальные действия «файл отправлен».

### Info (`f` / `F`)

Берётся только из нодлиста, без subst. В лог пишутся адрес, станция, город, сисоп, телефон, флаги, рабочее время и скорость.

## Окно линии

Пока рукопожатия нет, верхнее окно пустое, внизу лог линии. После EMSI или Binkp сверху карточка сессии:

- система и город, сисоп;
- скорость и флаги, телефон;
- адреса;
- `[pwd]` — в сессии был пароль;
- `[lst]` — узел есть в нодлисте;
- длительность сессии.

Ниже два прогресса: слева приём, справа передача. Для каждого: файл N из M, имя, скорость в cps, полоска текущего файла и полоска всего объёма с оценкой оставшегося времени.

| Клавиша | Что делает |
|---|---|
| **Up / Down** | лог на 1 строку |
| **Ins / Del** | лог на 2 строки |
| **PgUp / PgDn** | лог на страницу |
| **Home / End** | к началу / к концу буфера (256 строк) |
| `h` | повесить трубку. Сессии уходит hangup оператора. Для обычного модема дополнительно посылается SIGHUP процессу из lock-файла порта. Binkp и ifcico получают hangup сессии |
| `X` | пропустить текущий принимаемый файл. Действует в активной сессии |
| `R` | приостановить текущий файл (suspend). Действует в активной сессии |
| `c` | открыть чат, если протокол умеет чат (Hydra, Zmodem, Binkp) и сессия уже идёт |
| **F8** | убрать это окно с экрана. Сессия продолжается; окно появится снова со следующим событием линии |
| **Space** | как на master: сбросить паузу дозвона всего демона |
| `q` | выйти из qcc |

Пока сессии нет, `X`, `R` и `c` в подсказке приглушены и отвечают писком. В подсказке hangup и chat нарисованы как `H` и `C`; работают строчные `h` и `c`.

## Чат

`c` на линии открывает отдельное окно. Сверху — текст удалённой стороны, мигающий `_` в конце. Снизу — то, что набрали вы. Входящий bell заменяется на `*` и даёт писк и вспышку экрана.

| Клавиша | Что делает |
|---|---|
| обычные символы | сразу уходят в чат и печатаются снизу |
| **Enter** | перевод строки |
| **Backspace** | забой |
| **F2** | отправить целую строку (редактор `Text:`) |
| **F4** | послать bell |
| **Esc**, **F8** | закрыть чат |

**Tab** в чате переключает слоты так же, как в остальных окнах.

Если окно чата оказалось первым слотом (клавиша `1`, в заголовке `[1/…]` и других линий нет), ввод символов в чат в текущем коде не отправляется: обработчик чата смотрит слоты начиная со второго. Обычный порядок — сначала линия, затем отдельное окно чата — этой ветки не касается.

## Строка ввода

Один редактор используется для адреса, имён файлов и минут hold. На время ввода нижняя подсказка меняется.

| Клавиша | Действие |
|---|---|
| **Ins** | вставка / замена |
| **Left / Right**, **Home / End** | движение курсора |
| **Backspace**, **Del** | удалить символ |
| **Up / Down** | история, до 50 строк. Адреса, свободный текст и числа хранятся отдельно |
| **PgUp** | самая старая строка этого типа |
| **PgDn** | очистить поле |
| **Enter** | принять |
| **Esc**, **F8** | отмена |

Длина поля зависит от режима: адрес до 40 символов, минуты hold — до 5 цифр, имя файла и текст чата — длинная строка.
